# Реалізована локальна версія

Користувач обрав локальну версію без підключення Firebase. Старий застосунок, його конфігурація та дані не змінювалися.

## Архітектурні рішення

1. Самостійний Flutter-проєкт у `codelearn_next`. Жодних runtime-імпортів зі старого `lib`.
2. Feature-модулі; мовонезалежні моделі; asset-репозиторій контенту; окремий application-сценарій практики; транзакційний репозиторій локальних даних.
3. Sembast з окремими сховищами для профілів, завершень, сесій, портфоліо, спроб, журналу винагород і черги операцій. Веб використовує IndexedDB, мобільні платформи — файл у каталозі застосунку.
4. Одна транзакція для завершення уроку та всіх локальних наслідків. Повторне завершення того самого lesson ID не додає XP, кредити чи досягнення.
5. Стабільні ID контенту й версія сесії. Зміна версії уроку скидає несумісну сесію; застаріла сесія не може нарахувати прогрес.
6. Незалежні мови UI і навчання. ARB/gen-l10n для інтерфейсу. Мовні накладки за ID без виконуваних даних — для уроків. Немає перекладу через мережу під час навчання.
7. StatefulShellRoute з окремими гілками навігації. Курси й уроки відновлюються за ID з URL; передавання моделей через `state.extra` не потрібне.
8. Worker для практики у вебі; окремий процес/isolate або headless WebView на мобільних платформах. Є зупинка й timeout.
9. Firebase SDK винесений у необов'язковий окремий пакет. Основний застосунок не має ключів або production-залежності від старого Firebase.

## Підтверджені перевірки

- `flutter analyze --no-pub`: без зауважень.
- `flutter test --no-pub`: 22 тести, всі пройшли.
- Структура контенту: 145 уроків і 2160 текстових перекладів уроків, без помилок зв'язності ID.
- Еталонні рішення практики: 62 перевірки Dart/SQLite/Git/CLI/C++/HTML/CSS та 83 перевірки Python/JavaScript/JSX — усі пройшли.
- Окремий Firebase-пакет: аналізатор без зауважень. Серверна reward-policy: 6 тестів пройшли. Хмара не розгорталася й не заявляється перевіреною end-to-end.
- Зібрано вебреліз із локальними ресурсами, Android debug APK та iOS Simulator app без підписування.
- Вручну в браузері: вибір мови, 10 питань першого Python-уроку, правильний запуск коду, завершення з +35 XP / +8 кредитів, відновлення завершеного уроку після перезавантаження прямого URL, перемикання UI/контенту на українську зі збереженням прогресу.

## Межі підтвердження

Нативні збірки скомпільовані; фактичне виконання практики, звуків і нагадувань на фізичних Android/iOS-пристроях ще не перевірено. Браузерний Python перевірений у справжньому Worker. C++ є навчальною підмножиною; React/HTML/CSS мають структурну перевірку, без повного інтерактивного preview.

Імпортовані переклади потребують редактури. 305 накладок не відповідають актуальним урокам і використовують явний англійський fallback. Релізне підписування, публікація в магазинах, хмарна синхронізація та автоматична міграція старих production-акаунтів не входять до підтвердженої локальної версії.

CI лежить у `.github/workflows` нового проєкту й готовий для його окремого репозиторію. У поточному батьківському репозиторії вкладений workflow самостійно не запускається.
